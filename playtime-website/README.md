# PlayTime website

Static, responsive product landing page for the planned PlayTime Windows game-hours tracker.

## Running locally

Open `index.html` in a browser, or from this directory run:

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Hosting

Deploy the directory as a static website to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any standard web host. No build step or backend is required.

## Contents

- `index.html` — page markup and SEO metadata
- `styles.css` — responsive styles
- `app.js` — mobile menu and interactive dashboard sample
- `assets/favicon.svg` — lightweight PlayTime app icon
- `assets/playtime-brand.png` — original generated logo artwork

The displayed dashboard is illustrative sample data, not live user data. The Windows application is not included or represented as available for download. Replace the coming-soon area with a verified release link once one exists.
