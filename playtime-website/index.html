QUESTIONS & ANSWERS

Good to know.

The essentials about how PlayTime is designed to work.

Does it combine hours from multiple accounts?+

Yes. Each game has a single combined total, while individual Steam and Epic accounts can keep their own hour breakdowns.

Can I add hours I've already played?+

Yes. Enter the existing playtime for any game or account. Future tracked sessions add to that baseline instead of replacing it.

Will it automatically know which Epic account I'm using?+

Only when reliable account-identification information is available. Otherwise, sessions are left unassigned so you can choose the correct account without inaccurate guesses.

Does the app need an internet connection?+

No. The planned core tracking and database work locally. Optional launcher integrations may require an internet connection.

Is PlayTime available to download now?+

Not yet. This is the website for the planned application; a download button can be added when a tested Windows build is ready.
